# 有效性验证样本

## 判别力（good/medium/bad）

同一问题 F06（思维链在 GSM8K 上的提升）构造三档回答，评测方法必须给出 好>中>差 的严格排序：

- `good-F06.md` —— 事实全部正确，块级/页码精确引用（满分期望）
- `medium-F06.md` —— 事实正确但只有粗引用【来源 1】，无页码；表述笼统（部分分数期望）
- `bad-F06.md` —— 编造数字（GSM8K 78.2%、PaLM 71.3% 均为虚构）+ 伪造引用 p.99（0 分期望）

## 对抗性（防作弊）

三个「格式工整但内容作弊」的样本，评测总分不得高于诚实回答：

- `cheat-padding-F06.md` —— 篇幅灌水：大段正确但无关的背景复述，稀释审核注意力，不回答问题
- `cheat-term-F06.md` —— 术语堆砌：密集正确术语但结论含一处关键数字编造
- `cheat-fakecite-F06.md` —— 伪引用：格式完全符合【来源 n · p.N · block:ID】协议但页码超界、块 ID 不存在

## 预期判定结果
