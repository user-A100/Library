# Zotero 交互逻辑重新取证与本地重构

## 结论

本轮没有沿用此前可能被污染的产品结论。分析范围重新锁定到 Zotero 官方仓库 `786cdea8841d25883193002b69e5b3d09ba7e868`，并以源码调用关系重建本地交互。

当前应用已经从“可点击的展示稿”推进为一条可验证的 Zotero 式交互纵向切片：左侧树负责选择范围，中间是条目树，单击条目更新详情，双击或 Enter 激活附件，阅读器里的批注拥有类型、颜色、页码、位置、标签、评论和撤销历史。

## 已引入的 Zotero 交互

| Zotero 逻辑 | 本地实现 |
|---|---|
| 左侧 Library/Collection/虚拟集合选择 | 全部、最近、未分类、重复条目、回收站、集合和标签均切换中心列表 |
| 条目选择与激活分离 | 单击打开详情；双击或 Enter 打开附件 |
| 父条目与附件层级 | 条目可展开附件子行，附件独立激活 |
| 列排序 | 题名、作者、年份可切换升降序 |
| 条目详情面板 | 元数据、附件、所属集合、标签、笔记与回收站操作联动 |
| 集合多归属 | 同一条目可以加入多个集合，关系持久化 |
| 标签选择器 | 多标签组合筛选；条目标签和批注标签可独立编辑 |
| 虚拟集合 | 重复条目按规范化题名计算；回收站支持恢复 |
| 批注生命周期 | 高亮、下划线、便签、区域、手写；按 sortIndex 排序 |
| 批注筛选 | 类型、颜色、标签和文字查询组合生效 |
| 批注编辑 | 评论和标签可修改，高亮与下划线可互转 |
| 批注历史 | 50 步 undo/redo，支持 Ctrl/Cmd+Z、Shift+Ctrl/Cmd+Z、Ctrl/Cmd+Y |
| 批注进入笔记 | 笔记保留 paperId、annotationId、页码和标签来源 |
| 折叠侧栏 | 折叠后图标轨仍可进入文库、笔记、核验、搜索、AI 和项目 |

## 污染隔离

- 不信任旧报告作为实现依据，只重新运行官方源码检索。
- 本地持久化键升级到 `v3`，不会继续读取此前原型的 `v2` 状态。
- 工作区与集合重新分区，消除了同名项目/集合造成的重复导航。
- 右侧条目面板改为非模态，不再用遮罩阻断条目双击。

## 仍未完成的 Zotero 后端能力

当前不是完整 Zotero 替代品，以下能力仍需后续工程：

- 真实 PDF.js 渲染、选区和坐标持久化；
- DOI、RIS、BibTeX、网页快照与文件导入；
- SQLite/IndexedDB 数据库、全文索引和附件存储；
- CSL 引用样式与 Word/LibreOffice 插件；
- 同步、冲突解决、群组文库和权限；
- 重复条目合并，而不只是重复范围识别；
- 真正的 AI 模型与论文技能执行后端。
